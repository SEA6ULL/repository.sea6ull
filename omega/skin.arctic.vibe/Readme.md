Arctic Vibe is a minimal row based skin with customizable widgets. A modified fork of Arctic Fuse 2 by jurialmunkey.

Requires dependencies only available in Jurialmunkey's repo. AI was used to modify this skin. Changes are detailed inside the MOD_CHANGELOG so that a fresh AI agent can revert or mod further.

Highlights:

    Widget rows lowered to increase space for fanart.
    No Spotlight or Basic widgets.
    Trailers play fullscreen, not in a pop-up window.
    Option to keep album visible during playback (similar to Spotify).
    Streamlined first install wizard, fewer widgets on first run.
    Hub names added to hub settings window.
    "Soft White" color preset (matches skin default white color).
    Option to choose progress bar color (not tied to highlight color).
    Option to hide profile picture in Options window.
    Option to hide library section title in library windows.
